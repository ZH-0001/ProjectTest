# DeepSeek 预约助手 1.1.0 实现与验证

验收日期：2026-10-30。对应根目录《DeepSeek 自习预约助手接入方案》，没有新增数据库表或修改预约接口的原有契约。

## 接入验证与实际选择

- 采用 Spring AI 1.1.8 原生 DeepSeek starter、`deepseek-flash`，地址可配置。未采用 OpenAI 兼容适配器，也无需回退手写HTTP客户端。
- 1.1.8 原生选项未提供所需的thinking设置，使用 RestClient 拦截器将 `"thinking":{"type":"disabled"}` 写入实际HTTP请求体顶层；不是 `extra_body` 包装。收到非空reasoning内容时拒绝本轮。
- 关闭框架工具执行，由应用显式循环。模型只获得 `listRooms/searchSeats/myReservations` 三个工具定义；派发前再次校验名字，无全局工具解析或写工具。
- 实际HTTP请求单元测试验证thinking字段、三个工具定义、续传 `tool_call_id` 和工具结果；真实联调验证多轮工具调用及后续对话。
- 默认不重试HTTP请求。429、401/403和上游错误用自定义处理器转换为脱敏业务错误；测试验证每个上游错误只请求一次、响应不泄露上游原文。JDK HTTP请求超时取本轮剩余预算。

## 业务实现

`SearchCriteria`保存在服务端，以SET/CLEAR指令增量更新；批次校验失败不产生半次修改。六个字段中，时间始终硬约束；属性HARD先过滤，SOFT只影响评分。模型先查询自习室再选择ID，不接受模型传入其他用户身份。

每个维度分别采用本次偏好或历史比例，权重40/30/20/10。本次指定属性时匹配得该项满分，否则0；没有指定的维度使用全部已结束未取消预约及属性快照，无历史为0。计算及排序采用整数分子，展示才舍入到两位小数。四项显式返回来源EXPLICIT/HISTORY/NONE，普通推荐页与助手卡片都可展开。

`AssistantService`使用虚拟线程执行同步模型调用，以Semaphore限制5个实际任务。每轮最多4次模型请求、8次工具执行、60秒；取消后底层尚未退出的任务继续占名额。会话消息按完整轮次保留20轮，UUID去重先于忙碌判断与额度扣减，同UUID在途请求共用任务。

条件、消息与卡片在草稿中执行，整轮正常完成后检查会话版本并一次发布。重置或Session解绑递增版本、取消任务并清理数据，迟到回复无法写回。卡片100张／30分钟、请求结果200项／完成后30分钟，访问时与每分钟清理；用户滚动分钟和北京时间每日额度独立于Session。

预约卡片携带服务端生成的内部UUID，前端只提交cardId。先校验会话归属，再查本人原预约；存在原记录时重放原预约状态，否则校验2分钟有效期并调用原BookingService。继续沿用事务、行级锁与幂等约束。取消通过原接口再次校验身份、状态和开始时间。

## 真实调用记录

2026-10-30 21:03（北京时间），四轮对话总耗时约10.06秒，8次模型HTTP请求，4次工具执行，总token计数18,490。这里的token为每次响应usage的累计值，包含随上下文重复传送的输入，不能直接当作唯一文本长度或固定费用。

实际链路：listRooms → searchSeats → 回复；searchSeats修改开始时间 → 回复；解释现有四项分数 → 回复；myReservations → 回复。期间通过卡片调用业务服务完成预约。逐请求脱敏耗时和token报告位于 `backend/target/assistant-live-report.json`，构建目录不会纳入Git。

模型存在不确定性，开发联调曾触发4次调用上限；已补充参数示例与避免重复查询的提示，并验证正常链路。上限仍生效，超限整轮失败、不发布草稿，提示用户简化条件后重试；不能据一次成功承诺所有自然语言都能识别或每轮固定耗时。

## 复验

```powershell
# 默认：模拟模型 + 本机专用MySQL，不消耗DeepSeek额度
mvn -B -f backend/pom.xml test

# 显式真实联调：须配置本机密钥及DB_TEST_URL，会产生API费用
mvn -B -f backend/pom.xml "-Dtest=AssistantDatabaseTest#realDeepSeekSearchModifyExplainBookAndQuery" "-Dassistant.live=true" test

# Chrome浏览器；与数据库测试依次运行
cd frontend
npm run test:e2e
```

密钥只从后端环境变量或忽略的本地配置读取。测试默认关闭生产模型，真实调用必须显式开启。用户注册、登录、管理员密码与数据库配置要求见README。

当前只保存本机Session对话及内存额度；服务重启不恢复。没有流式输出、长期偏好、RAG、多实例同步、自动预约或实际到场确认。模型回复作辅助说明，操作和数据以服务端卡片及业务接口结果为准。
